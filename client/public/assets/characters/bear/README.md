# Bear chapter artwork (placeholder)

These files are generated by `scripts/make-bear-placeholders.py` (Pillow). They stand in until final storybook art is made the same way as the other chapters.

Saved assets:
- `client/public/assets/characters/bear/bear-v1.png` and `.json`: a drawn grizzly cub, 3×3 atlas with frames `idle blink happy / eat left down / right celebrate sad`
- `client/public/assets/objects/wolves/wolf-items-v1.png` and `.json`: frames `burrow ready item sent`, built from the existing bobcat-items den and wolf artwork
- `client/public/assets/backgrounds/ridge-v1.png`: a warm sunrise grade of `pine-v1.png`

To replace the art, keep the same paths and frame names; no code changes are needed. Then delete the placeholder script.
