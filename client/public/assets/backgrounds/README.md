# Environment art v1

Generated using the built-in imagegen tool and copied unchanged into the project. `meadow-v1.png` is used by the landing preview, Bunny’s Meadow, and the sanctuary. `garden-v1.png` is used by the Helper. These are independent backgrounds, not crops of the concept sheet. Phaser scales each with cover sizing to fill its viewport without side margins; characters and tappable objects remain separate layers. Some scenery near the edges can crop on tall viewports.
